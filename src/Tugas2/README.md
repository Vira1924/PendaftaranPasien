# 🏥 Pendaftaran Pasien – Modul 3 Tugas 2

## 📘 Deskripsi
Program ini dibuat berdasarkan hasil **refactoring dari program Modul 2** untuk latihan dokumentasi menggunakan **JavaDoc**.  
Aplikasi ini mensimulasikan proses **pendaftaran pasien di rumah sakit**, mencatat nama pasien, nama dokter, biaya dokter, biaya administrasi, dan menghitung total pembayaran pasien.

Program ditulis menggunakan bahasa **Java** dengan penerapan konsep **OOP (Object-Oriented Programming)** seperti:
- **Encapsulation (getter & setter)**
- **Introduce Constant**
- **Extract Method**
- **Rename Method**

---

## Struktur Program
Program terdiri dari dua kelas utama:

### 1️⃣ `PendaftaranPasien.java`
Berfungsi untuk menyimpan data pasien dan dokter, serta menghitung total biaya pembayaran.

**Fitur utama:**
- Menyimpan data pasien dan dokter
- Getter & Setter untuk setiap atribut
- Menghitung total biaya pasien
- Menampilkan data pasien dengan `printDataPasien()`

### 2️⃣ `Main.java`
Kelas utama yang menjalankan program dan menampilkan hasil ke layar.

---

## ⚙️ Cara Menjalankan Program
1. Buka proyek di **IntelliJ IDEA** atau **VS Code**.
2. Pastikan semua file berada di dalam package `Tugas2`.
3. Jalankan file `Main.java`.
